# ACERVO.md — Sistema de conocimiento histórico de Rafael Villegas

Versión: 1.0
Fecha: 2026-09-23
Visibilidad: public-safe

## Propósito
Preservar la evolución metodológica, comercial, editorial y visual de Rafael Villegas sin confundir material histórico con verdad vigente.

La fuente documental detallada del acervo vive fuera de este repositorio público, en la Biblioteca/Drive autorizados. Este repo solo conserva criterios, decisiones y referencias públicas seguras.

## Principio
**La antigüedad no vuelve irrelevante a un archivo; la falta de valor, trazabilidad o singularidad sí puede volverlo candidato a descarte.**

Antes de eliminar:
1. inventariar;
2. clasificar;
3. detectar duplicados;
4. validar vigencia;
5. extraer conocimiento reusable;
6. asignar canonicalidad;
7. obtener aprobación humana;
8. archivar/eliminar y registrar.

## Estados
- CANÓNICO — fuente vigente aprobada.
- REUTILIZABLE — útil, requiere actualización.
- HISTÓRICO — evidencia de evolución; no gobierna decisiones actuales.
- REFERENCIA EXTERNA — inspiración de terceros.
- RESTRINGIDO — datos sensibles o personales.
- DUPLICADO CANDIDATO — no borrar sin confirmación.
- ELIMINAR-TRAS-APROBACIÓN — sin valor operativo/histórico suficiente y con aprobación de Rafa.

## Seguridad
Credenciales, PIN, API keys, tokens y secretos no pertenecen al acervo documental ni a GitHub.
Cuando se detecten, deben migrarse a un gestor seguro y el archivo inseguro solo podrá retirarse después de validación humana.

## Relación con eXeT
Cuando un material histórico cambie o confirme metodología vigente de programas/talleres, la conclusión debe reconciliarse con el repo eXeT. No convertir historia en metodología actual de forma automática.

Material histórico con otra ortografía puede conservarse como evidencia, pero no gobierna nuevos activos.
